# hamon — Version 0.1

クリック・タップした場所から波紋が広がる、最小構成のWebアプリです。

## ファイル

- `index.html` — HTML / CSS / JavaScriptをまとめたアプリ本体
- `README.md` — この説明書

## 実行方法

PCでは `index.html` をブラウザで開くだけで動きます。インストールやビルド、外部ライブラリは不要です。

スマートフォンから確認する場合は、PCと同じWi-Fiに接続し、このフォルダで簡易HTTPサーバーを起動します。Pythonがある場合の例：

```powershell
python -m http.server 8000 --bind 0.0.0.0
```

スマートフォンのブラウザで `http://<PCのローカルIPアドレス>:8000` を開きます。PCのIPアドレスは `ipconfig` のIPv4アドレスで確認できます。必要に応じてファイアウォールでプライベートネットワークからの接続を許可してください。終了は `Ctrl+C` です。

## 操作と動作

- 水面をクリックまたはタップすると、その位置から3本の輪が広がります。それぞれ移動距離に応じて薄くなり、同じ半径（288 CSS px）で消えます。外側は約2.6秒、真ん中は約2.76秒、内側は約2.92秒で消えます。
- 連続して操作すると複数の波紋が同時に表示され、重なります。
- 輪の線幅は内側から1.8 / 2.25 / 3 CSS pxで、線の内外の縁を暗く、幅の中心を明るくするグラデーションを付けています。
- 画面左側の下半分にある縦スライダーで、ランダムな位置に波紋を発生させる雨の強さを変更できます。
- 上端の `yamu` は秒間0タップ、下端の `furu` は秒間60タップです。起動時は必ず0から始まります。
- 強さはスライダー位置の1.5乗で計算し、上側ほど緩やかに、下側ほど大きく変化します。中央では約21タップ/秒です。
- スライダーを急に動かしても、雨の強さは約3秒かけて目標の強さへ滑らかに近づきます。
- 自動タップの間隔は、現在の強さに応じた標準間隔から毎回ランダムに±30%ずれます。
- 雨が降っている間も水面を直接クリック／タップできます。雨を止めると、残った波紋は自然に消えます。
- ブラウザのサイズ変更やスマートフォンの画面回転に対応しています。
- Canvas 2DとPointer Eventsを使用します。波紋の重なりは視覚表現で、物理的な干渉のシミュレーションは行いません。
